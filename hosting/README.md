# Hosting Directory

This directory can be used for static assets if you configure Firebase Hosting (classic) to point here via `firebase.json` (e.g., `"hosting": { "public": "hosting", ... }`).

The main Next.js application for this project resides at the project root and is intended for deployment via Firebase App Hosting (see root `firebase.json` and `apphosting.yaml`) or other Next.js compatible platforms like Netlify/Vercel pointing to the project root.
