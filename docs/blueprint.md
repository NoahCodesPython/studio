# **App Name**: Persona

## Core Features:

- Intro Section: Clean and professional landing page with a brief introduction.
- Portfolio Showcase: Portfolio display with project tiles and descriptions.
- Resume Section: A well written resume should be available in .pdf and shown within the browser itself.
- Contact Form: Contact form for potential employers.
- Dynamic Intro Generator: AI-powered tool that generates personalized introductory messages based on the viewer's profile (if available).
- Dark/Light Mode Switcher: A switch that allows the user to switch between dark and light mode.
- Domain Publishing: Publishing to my own domain
- GitHub Copilot Integration: Integration with GitHub Copilot and Firebase workspace

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) for a sense of depth and intellect.
- Background color: Light gray (#F0F2F5) for a clean and modern feel.
- Accent color: Cyan (#00BCD4) to highlight interactive elements and CTAs.
- Clean and modern sans-serif fonts for body text and headings.
- Grid-based layout with clear sections for easy navigation.
- Subtle hover animations for project tiles and buttons to add interactivity.
- Particles in the background to make the website more modern.
